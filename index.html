01 / FUNDAMENTOS

O que é HTML5?

HTML significa HyperText Markup Language, ou Linguagem de Marcação de Hipertexto.

O HTML é como o esqueleto de uma página: ele organiza títulos, textos, imagens, vídeos e botões.

HTML5 é a versão atual. Ela traz recursos novos para deixar as páginas mais completas. Depois, o CSS cuida das cores e o JavaScript faz as coisas se mexerem.

02 / HISTÓRIA

Uma evolução contínua.

1991
HTML 1.0

O começo da Web

As primeiras páginas podiam mostrar textos e ligar um conteúdo a outro.

1995
HTML 2.0

As regras ficaram públicas

Surgiram elementos mais organizados e os primeiros formulários.

1997
HTML 3.2

Tabelas e scripts

A linguagem ganhou recursos para organizar dados e adicionar pequenas ações.

1999
HTML 4.01

Estrutura e estilo separados

O HTML passou a cuidar da estrutura e o CSS passou a cuidar da aparência.

2000
XHTML

Uma versão mais rígida

Essa versão exigia código muito organizado, mas acabou sendo menos prática.

2014+
HTML5

Uma plataforma completa

Agora o HTML ajuda em vídeos, jogos, gráficos, formulários e muito mais.

03 / ANATOMIA

Estrutura de um
documento HTML5.

index.html
<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Minha primeira página</title>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
    <p>Minha primeira página HTML5.</p>
  </body>
</html>
01

<!DOCTYPE html>

Avisa ao navegador que esta página usa HTML moderno.

02

<html lang>

Guarda toda a página e informa em qual idioma ela está.

03

<head>

Contém informações da página, como título, estilos e scripts.

04

<meta viewport>

Ajuda o site a se ajustar ao tamanho da tela do aparelho.

05

<body>

Contém tudo o que aparece na tela: textos, imagens e botões.

17 / RESUMO FINAL

Você conhece
como a Web é construída.

O HTML organiza tudo o que aparece em uma página. Na prática, ele trabalha com três ideias principais:

Estrutura

Tags separam títulos, textos, links, imagens e regiões importantes.

Significado

HTML semântico explica o papel de cada parte para pessoas e navegadores.

Conexão

Com CSS e JavaScript, o HTML ganha aparência, animações e interações.

EXEMPLOS NA PRÁTICA

Onde você encontra isso?

O HTML está em sites que usamos todos os dias. Veja três exemplos.

NO BRASIL

Serviços públicos no celular

Um formulário de matrícula ou agendamento pode se adaptar à tela pequena. HTML organiza os campos; CSS ajuda a página a caber no celular.

NO BRASIL E NO MUNDO

Página que mais pessoas conseguem usar

Títulos bem organizados, textos alternativos e botões claros ajudam leitores de tela e quem navega pelo teclado.

NO MUNDO

Aulas, vídeos e músicas

Etiquetas como <video> e <audio> colocam mídia na página. Legendas podem ajudar quem não ouve o áudio.

BRASILImpactos positivos
  • Facilita o ensino de programação em escolas e cursos gratuitos.
  • Ajuda empresas brasileiras a criar sites acessíveis e responsivos.
  • Permite criar serviços públicos digitais que funcionam em celulares.
  • Reduz custos: HTML, CSS e navegadores modernos têm acesso gratuito.
BRASILDesafios negativos
  • Má conexão pode atrasar páginas grandes com muitos recursos.
  • Conteúdo mal organizado dificulta o uso por pessoas com deficiência.
  • Profissionais podem usar tags antigas ou código ruim sem validação.
  • Dados coletados por sites precisam ser protegidos pela LGPD.
MUNDOImpactos positivos
  • Padroniza sites para muitos dispositivos e idiomas.
  • Permite aplicações como educação, comércio e comunicação pública.
  • Vídeo, áudio, gráficos e formulários existem sem plugins antigos.
  • Promove mais inclusão quando é usado com semântica e acessibilidade.
MUNDODesafios negativos
  • Sites podem ampliar desigualdade entre pessoas com pouco acesso à internet.
  • Recursos modernos nem sempre funcionam em aparelhos antigos.
  • HTML mal usado pode revelar informações ou facilitar rastreamento.
  • Acesso fácil também permite desinformação e páginas fraudulentas.
