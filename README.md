# HTML5 — O Guia Definitivo

Guia educacional completo e responsivo sobre HTML5, criado com HTML, CSS e JavaScript puros.
Inclui uma aula em vídeo local em `assets/aula-html5.mp4`.

## Executar localmente

```bash
python3 -m http.server 4173
```

Depois acesse `http://localhost:4173`.

## Publicação

O site é publicado pelo GitHub Pages na branch `main`, usando a raiz do repositório.
O vídeo é servido junto com o site; mantenha o arquivo em `assets/aula-html5.mp4`.
